SHA256SUMS has no header. Each line is three fields separated by two spaces:

  sha256  bytes  path

sha256 is 64 lowercase hex digits. bytes is the decimal file size. path is
relative to this directory and has no leading slash. Example check:

  python3 -c 'import hashlib,pathlib,sys
p=pathlib.Path(sys.argv[1])
print(hashlib.sha256(p.read_bytes()).hexdigest(), p.stat().st_size)' acceptance.bundle
