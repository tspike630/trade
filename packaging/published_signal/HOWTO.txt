PR 208 acceptance kit. Not a deploy and not a merge. No .env and no database copy.

The archive contains acceptance.bundle, this file, run_acceptance.py, and
SHA256SUMS. The bundle is a local git bundle. Do not clone GitHub.

SHA256SUMS lines have three fields separated by two spaces, and no header:

  sha256  bytes  path

sha256 is 64 lowercase hex digits. bytes is the decimal size of the file.
path is relative to this directory. Two spaces, not one, sit between fields.
Check a line with:

  python3 -c 'import hashlib,pathlib,sys
p=pathlib.Path(sys.argv[1]); d=hashlib.sha256(p.read_bytes()).hexdigest(); print(d, p.stat().st_size, sys.argv[1])' <path>

Materialize the checkout from the bundle only:

  git clone --branch cursor/publish-state3-signal-cf2e acceptance.bundle repo
  git -C repo fetch acceptance.bundle ab2d2eb:refs/remotes/origin/main
  git -C repo fetch acceptance.bundle bc392fea:refs/tags/bc392fea-mark
  git -C repo update-ref bc392fea ab2d2eb
  # The next command restores the real bc392fea commit named by that object.
  git -C repo fetch acceptance.bundle bc392fea:bc392fea

If `git fetch acceptance.bundle bc392fea:bc392fea` is run from inside repo,
use the bundle path. Then:

  python3 repo/packaging/published_signal/run_acceptance.py
